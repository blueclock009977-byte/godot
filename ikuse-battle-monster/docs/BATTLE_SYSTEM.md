# バトルシステム詳細

ポケモンバトルを参考に、共有マナ制を組み合わせた独自システム。

---

## 📊 基本ステータス

### ステータス一覧
| ステータス | 略称 | 説明 |
|------------|------|------|
| HP | HP | 体力。0になると戦闘不能 |
| こうげき | ATK | 物理技のダメージに影響 |
| ぼうぎょ | DEF | 物理技の被ダメージに影響 |
| すばやさ | SPD | 行動順に影響 |
| とくこう | MAG | 特殊技のダメージに影響 |
| とくぼう | RES | 特殊技の被ダメージに影響 |

### 種族値
- **早熟モンスター**: 合計450
- **普通モンスター**: 合計490
- **晩成モンスター**: 合計530
- **御三家**: 合計490（固定構成）

## ⚔️ ダメージ計算式

### 基本式
```
ダメージ = ((攻撃側レベル × 2 / 5 + 2) × 技威力 × A / D / 50 + 2) × 各種補正
```

**簡略版（レベル50固定の場合）:**
```
ダメージ = (22 × 技威力 × A / D / 50 + 2) × 各種補正
```

### 変数
- **A**: 物理技なら攻撃側のATK、特殊技ならMAG
- **D**: 物理技なら防御側のDEF、特殊技ならRES

### 各種補正（乗算）
| 補正 | 倍率 | 条件 |
|------|------|------|
| タイプ一致（STAB） | 1.5倍 | 技タイプが使用者のタイプと一致 |
| 相性有利 | 2.0倍 | タイプ相性表参照 |
| 相性不利 | 0.5倍 | タイプ相性表参照 |
| 急所 | 1.5倍 | 急所に当たった場合 |
| 乱数 | 0.85〜1.00 | 毎回ランダム |
| 天候 | 1.5倍 or 0.5倍 | 天候と技タイプの組み合わせ |
| やけど | 0.5倍 | 物理技使用時、攻撃側がやけど状態 |

### ダメージ例
```
ATK100のモンスターが威力80の物理技を DEF80の相手に使用:
= (22 × 80 × 100 / 80 / 50 + 2)
= (22 × 100 / 50 + 2)
= (44 + 2)
= 46ダメージ（補正なし）

タイプ一致 + 相性有利の場合:
= 46 × 1.5 × 2.0 = 138ダメージ
```

```
最終命中率 = 技の命中率 × (命中ランク補正 / 回避ランク補正)
```

## 💨 行動順

### 基本ルール
1. **先制技**が最優先（優先度で決定）
2. 同じ優先度なら**すばやさ(SPD)**が高い方が先に行動
3. SPDも同じなら**ランダム**

### 優先度
| 優先度 | 例 |
|--------|-----|
| +4 | まもる、みきり |
| +3 | ねこだまし、フェイント |
| +2 | しんそく |
| +1 | でんこうせっか、アクアジェット、マッハパンチ |
| 0 | 通常の技 |
| -1 | あてみなげ |
| -3 | きあいパンチ |
| -5 | ほえる、ふきとばし |
| -6 | カウンター、ミラーコート |
| -7 | ほろびのうた |

### 交代のタイミング
- **交代は技使用前**に処理
- 追い打ち系の技は交代時に2倍ダメージ

## 🎲 急所（クリティカル）

### 急所率
| 急所ランク | 確率 |
|------------|------|
| 0 | 1/24 (約4.2%) |
| +1 | 1/8 (12.5%) |
| +2 | 1/2 (50%) |
| +3以上 | 確定 (100%) |

### 急所の効果
- ダメージ **1.5倍**
- **攻撃側の能力下降を無視**
- **防御側の能力上昇を無視**

### 急所ランクを上げる要素
- 特定の技（きりさく、ストーンエッジなど）: +1
- 特性「きょううん」: +1
- 特性「スナイパー」: 急所時ダメージ2.25倍

## 🔥 状態異常

### 主要な状態異常
| 状態 | 効果 | 回復 |
|------|------|------|
| **どく** | 毎ターン終了時にHP 1/8 ダメージ | 交代で回復しない |
| **もうどく** | 毎ターン増加（1/16→2/16→...） | 交代でリセット |
| **やけど** | 物理技威力0.5倍 + 毎ターンHP 1/16 | 交代で回復しない |
| **まひ** | SPD 0.5倍 + 25%で行動不能 | 交代で回復しない |
| **こおり** | 行動不能（毎ターン20%で解除） | 炎技を受けると解除 |
| **ねむり** | 1〜3ターン行動不能 | ターン経過で回復 |
| **こんらん** | 33%で自傷ダメージ | 1〜4ターンで回復 |

### 状態異常の重複
- **主要状態異常**（どく/やけど/まひ/こおり/ねむり）は**重複しない**
- **こんらん**は主要状態異常と**重複する**

## 🔄 交代

### 交代のルール
- **マナ消費なし**（無料）
- 技より先に処理される
- 交代先は控えから選択
- 交代時に能力変化リセット

### 交代を制限する技・特性
| 効果 | 例 |
|------|-----|
| 逃げられない | かげふみ、ありじごく、くろいまなざし |
| 交代時ダメージ | ステルスロック、まきびし |
| 交代時追撃 | おいうち |

### 強制交代
- ほえる、ふきとばし: ランダムに交代させる
- ドラゴンテール、ともえなげ: ダメージ+強制交代

---

## ⏸️ 待機

### 待機のルール
- **マナ消費なし**
- 何もせずターンを終了
- マナを温存したい時に使用
- 状態異常のターンは経過する

---

## 🎮 バトルフロー（1ターン）

### 処理順序
```
1. ターン開始
   └─ 天候ダメージなどの処理

2. 行動選択（同時選択）
   ├─ 技を選ぶ
   ├─ 交代する
   └─ 待機する

3. 行動解決
   ├─ 3-1. 交代処理（両者同時なら速い方が先）
   ├─ 3-2. 技処理（優先度→SPD順）
   │   ├─ 命中判定
   │   ├─ ダメージ計算
   │   ├─ 追加効果判定
   │   └─ 瀕死判定
   └─ 3-3. 待機（何もしない）

4. ターン終了
   ├─ 状態異常ダメージ（どく、やけど等）
   ├─ 天候ダメージ
   ├─ 回復効果（たべのこし等）
   └─ その他の効果
```

## 🏆 勝利条件

### 勝利判定
- **相手のモンスター3体すべてを倒す**
- 両者同時に最後の1体が倒れた場合 → **後攻側の勝利**

### 降参
- いつでも降参可能
- 降参したら即座に敗北

## 💎 共有マナシステム（独自要素）

### マナの基本
| 項目 | 値 |
|------|-----|
| 初期マナ | 10 |
| 毎ターン回復 | +3 |
| 最大マナ | 20 |

### マナ消費
- **技ごとに異なる**（1〜12）
- **交代**: 無料
- **待機**: 無料

### マナ戦略
```
序盤戦略:
├─ 低コスト技で削り → マナ温存
├─ 高コスト技で速攻 → 数的有利狙い
└─ バフ技で積み → 後半勝負

終盤戦略:
├─ 残りマナで大技
├─ マナドレインでリソース奪取
└─ マナバースト（残り全消費）
```

### マナ操作技
| 技 | マナ | 効果 |
|----|------|------|
| マナチャージ | 0 | 待機、次ターンマナ+5 |
| マナドレイン | 5 | 相手のマナを3奪う |
| マナバースト | 全 | 残りマナ×20の固定ダメージ |
| マナシール | 4 | 次ターン相手のマナ回復0 |

## 📊 ダメージ計算例

### 例1: 基本ダメージ
```
攻撃側: ATK 100
防御側: DEF 80
技: 威力80の物理技

ダメージ = (22 × 80 × 100 / 80 / 50 + 2)
        = (22 × 100 / 50 + 2)
        = (44 + 2)
        = 46

乱数補正（0.85〜1.00）: 39〜46ダメージ
```

### 例2: タイプ一致 + 相性有利
```
上記 + STAB + 弱点
= 46 × 1.5 × 2.0
= 138ダメージ

乱数補正: 117〜138ダメージ
```

### 例3: 急所
```
上記 + 急所
= 138 × 1.5
= 207ダメージ

乱数補正: 175〜207ダメージ
```
