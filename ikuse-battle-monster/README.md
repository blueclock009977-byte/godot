# 育成モンスターバトル

ポケモン風のターン制モンスターバトルゲーム。Next.js + TypeScriptで実装。

## 特徴

- **40体のモンスター**: 各タイプ5体 × 8タイプ
- **147種の技**: 物理/特殊/変化の多彩な技
- **8タイプ相性**: 炎、水、草、電気、岩、風、闇、光 + 無属性
- **マナシステム**: 毎ターン回復するリソースで技を使用
- **状態異常**: やけど、毒、麻痺、睡眠、凍結、混乱
- **天候システム**: 晴れ、雨、砂嵐、霧
- **44種の特性**: モンスター固有の能力

## 起動方法

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで http://localhost:3000 を開く。

## 画面

- `/` - トップページ
- `/battle` - バトル画面（AI対戦）

## ディレクトリ構成

```
ikuse-battle-monster/
├── app/                    # Next.js App Router
│   └── page.tsx           # トップページ
├── src/
│   ├── app/battle/        # バトル画面
│   ├── components/battle/ # バトルUIコンポーネント
│   ├── hooks/             # React Hooks
│   └── lib/
│       ├── battle/        # バトルロジック
│       ├── data/          # マスターデータ
│       └── types/         # 型定義
└── docs/                  # 設計ドキュメント
```

## 技術スタック

- **Next.js 15** - React フレームワーク
- **TypeScript** - 型安全
- **Tailwind CSS** - スタイリング
